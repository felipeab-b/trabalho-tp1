\doxysubsection{Detailed Description}
Classe base abstrata para todos os domínios do sistema. 

Define a interface comum de acesso (set/\+get) compartilhada por todos os domínios. Cada subclasse deve implementar \doxylink{classDominio_a3ed716bcf8a87405351e5de8fea56850}{validate()} com suas próprias regras de validação.
