\doxysubsection{Detailed Description}
Domínio que representa o código identificador de uma entidade. 

O código é composto por exatamente 5 caracteres:\+ os dois primeiros devem ser letras maiúsculas (A-\/Z) e os três últimos devem ser dígitos (0-\/9). Exemplo:\+ "{}\+AB123"{}.
