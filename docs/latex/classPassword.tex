\doxysubsection{Detailed Description}
Domínio que representa a senha de acesso de um usuário. 

A senha deve ter exatamente 6 caracteres alfanuméricos, alternando obrigatoriamente entre letras e dígitos. Deve conter ao menos uma letra minúscula (a-\/z), uma letra maiúscula (A-\/Z) e um dígito (0-\/9). Exemplo válido:\+ "{}a1\+B2c3"{}.
